# FocusFlow - Gerenciador de Tarefas
Um gerenciador de tarefas moderno e minimalista desenvolvido com HTML, CSS e JavaScript puro, focado na organização pessoal e acompanhamento de progresso.

---

## Funcionalidades
- **Adição de Tarefas**: Permite cadastrar tarefas definindo o nome e a duração em minutos.
- **Acompanhamento de Progresso**: Barra de progresso dinâmica e contador que atualizam em tempo real conforme as tarefas são concluídas.
- **Marcação de Conclusão**: Alternância do status da tarefa com indicação visual.
- **Remoção de Tarefas**: Exclusão simples de itens da lista.

---

## Tecnologias Utilizadas
- **HTML5**: Estruturação semântica da aplicação.
- **CSS3**: Estilização moderna em modo escuro (*Dark Theme*), layouts flexíveis (*Flexbox*) e transições suaves.
- **JavaScript (ES6+)**: Manipulação do DOM, gerenciamento de estado e renderização dinâmica da interface.

---

## Como Executar o Projeto
Como o projeto utiliza apenas tecnologias nativas do navegador, não é necessária nenhuma instalação de dependências ou servidores.

1. Clone este repositório:
    ```bash
    git clone https://github.com/SEU_USUARIO/focusflow.git

2. Abra a pasta do projeto.

3. Clique duas vezes no arquivo index.html para abrir diretamente no navegador (ou utilize a extensão Live Server no VS Code).
